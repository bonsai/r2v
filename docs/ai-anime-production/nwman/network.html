NETWORK DESIGN / PRIVATE LAN

nwman — LAN-only AI anime production network

LAN内のみ。制作端末、生成ワーカー、JEV評価、素材保管を内部ネットワークに閉じ込め、将来のKubernetes移行に備えてサービス境界を分離する。

この資料は論理設計であり、実機のIPアドレスや稼働済み構成ではない。最初のPoCにKubernetesは不要。

Studio

制作端末、レビューUI、管理端末。内部APIを通してジョブを投入する。

Control plane

内部DNS、Job API、キュー、認証・権限、ログ・メトリクス。

Worker plane

R2V生成、JEV評価、後処理。通常の生成ワーカーはインターネットへ接続しない。

Data plane

参照原本、生成候補、採用素材、メタデータ、実験ログ、RAG/SQLiteを分離して保存。

ネットワーク原則

  • 公開インターネットからの着信は拒否。
  • 外向き通信は既定拒否。モデルやデータセットは管理端末から許可リスト経由で取得。
  • 取得時に出典、ライセンス、チェックサムを記録。
  • サービス間はAPI／キューを介し、最小権限と監査ログを適用。
  • Kubernetes移行時はNamespace、Service、Job、PVC、NetworkPolicy、RBACへ対応づける。
