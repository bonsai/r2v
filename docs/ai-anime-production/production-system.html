PRODUCTION ARCHITECTURE / RESEARCH HYPOTHESIS

AIアニメ映画制作システム

生成をお呪いから科学へ、錬金術から工場へ。

棒人間 × YAML × JEV × LoRA × MLアダプターを接続し、制作の再現性・品質・効率を改善できるか検証する。

4つのレイヤー

1. Reference

何を作るか

脚本、キャラクター、世界観、棒人間、絵コンテ、YAML仕様を正本として管理する。

TEXT / YAML / PNG / HTML / SVG / RAG

構造化データが正本。RAGは検索用。

2. Generation

どう候補を作るか

棒人間でポーズやタイミングを明示し、モデル・LoRA・MLアダプター・プロンプト・参照版・seedを記録する。

候補と採用済み素材を区別する。

3. Eval / JEV

何を合格とするか

命題・証拠・評価基準・スコア・確信度を結び付け、合否と失敗理由を記録する。

PASS / REVISE / REJECT / NEEDS_HUMAN_REVIEW

4. Production System / TPS-Gate

どう完成まで流すか

Gate A：仕様、B：素材、C：ショット、D：納品。合格した素材だけを次工程へ流す。

待ち・手戻り・重複生成・廃棄を減らす。

閉ループ

脚本・世界観 → YAML仕様 → 棒人間／絵コンテ → LoRA・MLアダプターを使った生成 → JEV評価 → TPS/Gate → 編集・納品。

不合格時：原因に応じて仕様、ポーズ、生成条件、評価基準の該当箇所へ戻す。全工程を無差別に再生成しない。

検証計画

  1. 通常生成をベースラインにする。
  2. YAML仕様を追加する。
  3. 棒人間／ポーズ制御を追加する。
  4. キャラクターLoRAを追加する。
  5. MLアダプターとJEVフィードバックを追加する。

同じシーンと評価基準を使い、可能な範囲で生成条件を揃える。ポーズ一致、キャラクター一貫性、時間的連続性、初回合格率、手戻り率、合格ショットあたりコストを測定する。仮説は未検証であり、JEVの判定も人間の抜き取り評価と照合する。
